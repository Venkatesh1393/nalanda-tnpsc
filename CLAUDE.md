# Nalanda TNPSC

## Project Goal

Build the most advanced AI-powered TNPSC Preparation Platform for Tamil Nadu.

The application should support

- Group 1
- Group 2
- Group 2A
- Group 4
- VAO
- Police
- Forest
- TRB

## Tech Stack

Frontend

- React
- Vite
- TypeScript
- TailwindCSS
- Framer Motion

Backend

- Node.js
- Express

Database

- MongoDB Atlas

Authentication

- Firebase Authentication
- Google Login
- Email OTP

Payments

- Razorpay

Storage

- Cloudinary

Charts

- Chart.js
