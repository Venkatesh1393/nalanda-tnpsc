# backend/docs/

Backend-specific documentation that doesn't belong in the repo-root `docs/`
(which covers product/design/architecture decisions read by every app). This
folder is for implementation-facing material as it's produced — an OpenAPI/
Swagger spec once real endpoints exist, ADRs for backend-only decisions, and
runbooks.

Empty as of this scaffold (Sprint 3 foundation step). The repo-root
`docs/API.md`, `docs/Database.md`, and `docs/Architecture.md` remain the
authoritative specs to build against until this folder has its own content.
