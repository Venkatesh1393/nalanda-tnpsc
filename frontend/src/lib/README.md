# lib/

Low-level, framework-agnostic helpers with no React/UI dependency — the
frontend-local equivalent of the "Utilities" layer described in
`docs/FolderStructure.md`.

- `utils.ts` — the `cn()` class-name merge helper, generated by the shadcn/ui
  CLI and required by every `components/ui` primitive. Keep it here (shadcn's
  own convention) rather than moving it, since the CLI's generated components
  import it from this exact path.
- `env.ts` — validates `import.meta.env` once at startup (via Zod) and
  exports a typed `env` object; import from here instead of reading
  `import.meta.env` directly anywhere else in the app.
- `query-client.ts` — the shared React Query `QueryClient` instance.
